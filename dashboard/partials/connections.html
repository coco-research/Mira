Pod mode

Pair & share capacity

Solo mode — pod features off

Pod mode lets friends run their own Mira Agent and share available quota across the group — capacity only, never keys. Enable by signing in and joining a pod.

Sign in with Supabase Auth Creates your pod identity — no keys are ever stored in Supabase
Join a pod by invite Paste the invite link or code a friend shared with you
Pair this machine's Mira Agent Generates a one-time pairing code; shows agent online/offline and assigned channels in the pod
Opt your own accounts into the swarm NIM · OpenRouter · Mistral · Groq · Cerebras · Cloudflare · GitHub Models · Gemini · Veo · AWS — only available capacity is published to the pod ledger, never keys
Pod features activate after sign-in. Keys stay in your local .env; Supabase holds only coordination metadata (roles, queue, job status). Your machine pulls only its assigned jobs — no inbound connections or tunnels ever open.
