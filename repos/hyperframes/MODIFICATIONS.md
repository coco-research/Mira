# Modifications to HyperFrames in Mira

HyperFrames is licensed under the Apache License 2.0 (see `LICENSE`). Section 4(b) asks that modified files carry prominent notices saying they were changed. This file lists the changes Coco made in Mira. Each modified file that can hold a comment also carries a short notice pointing here.

## 2026-10-08: third-party fonts removed or licensed (lab-0062 legal review)

|                           |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Removed**               | `packages/producer/tests/heygen-promo-preview-assets/src/ABCSolarDisplay-Bold.woff2`, `TT_Norms_Pro_Normal.woff2`, `TT_Norms_Pro_Medium.woff2`, `TT_Norms_Pro_Bold.woff2` (commercial fonts, no licence). Everything in `skills/embedded-captions/assets/brand/`: a fan-made replica of a video-game logo typeface, its fan-kit terms (which forbid commercial use) and the glyph widths measured from that fan kit. `skills/graphic-overlays/assets/fonts/Virgil.woff2` (licence not confirmed: the upstream repository says OFL, but the font's name table says "Freeware for personal use").                                                                                                                                                           |
| **Added**                 | `skills/graphic-overlays/assets/fonts/OFL-caveat.txt`, `OFL-inter.txt`, `OFL-lxgw-wenkai-tc.txt`: the SIL OFL 1.1 texts for the bundled fonts, copied byte for byte from upstream (sources and commits in Mira's `THIRD-PARTY.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Files edited to match** | `packages/producer/tests/heygen-promo-preview-assets/output/compiled.html` (the golden output's `@font-face` rules for the removed fonts are gone, so text uses the existing Arial / sans-serif stacks) and `meta.json` (description; JSON cannot hold a comment). `skills/embedded-captions/scripts/make-theme.cjs` (the `coverword` setpiece now sets the word in the bundled Anton face, SIL OFL 1.1, and lays it out from `assets/fonts/anton-glyph-metrics.json`, generated from that font by the new `scripts/gen-glyph-metrics.py`), `themes/README.md` and `.gitignore`. `skills/graphic-overlays/SKILL.md`, `references/DESIGN_INDEX.md` and `references/styles/editorial.html` (Virgil no longer listed; Caveat or system `cursive` suggested). |
| **Reason**                | Mira is distributed under AGPL-3.0. HyperFrames' Apache-2.0 licence does not cover third-party fonts, so every shipped font file must have its licence text beside it or be removed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## 2026-10-08: embedded fixture fonts, licence texts and metrics generator (lab-0062 re-review)

|                  |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Removed**      | 50 base64 `@font-face` blocks for commercial system fonts (Helvetica Neue / Linotype; Helvetica, Impact, Garamond / Monotype) from the golden outputs `packages/producer/tests/{style-3-prod,style-7-prod,style-8-prod,style-15-prod,style-16-prod,style-18-prod,sub-comp-id-selector,sub-comp-t0}/output/compiled.html`. The folder has no `src/index.html`, so the test runner does not treat it as a fixture.                                                                                                                                                                                                                                                                                                                                      |
