# Modifications to HyperFrames in Mira

HyperFrames is licensed under the Apache License 2.0 (see `LICENSE`). Section 4(b) asks that modified files carry prominent notices saying they were changed. This file lists the changes Coco made in Mira. Each modified file that can hold a comment also carries a short notice pointing here.

## 2026-10-08: no bundled subset under a Reserved Font Name; stricter font checks (lab-0062, review round 4)

|                  |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

| **Removed**      | The `playfair-display`, `source-code-pro` and `lato` entries from the producer's bundled fonts (`CANONICAL_FONTS` in `packages/producer/src/services/deterministicFonts.ts` and `scripts/generate-font-data.ts`) and their display names in `packages/core/src/fonts/aliases.ts`. Their OFL texts reserve "Playfair Display", "Source" and "Lato", and the bundled Fontsource faces are subsets.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Added**        | `packages/producer/scripts/check-golden-font-licences.test.mjs` (one test per bypass found in review, plus the bundled-data check). `skills/embedded-captions/modes/standard/fonts/build-fonts-css.test.cjs`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Files edited** | `packages/core/src/fonts/aliases.ts`: "playfair display" now aliases to EB Garamond, "source code pro" to JetBrains Mono and "lato" to Inter, all bundled and with no Reserved Font Name. `packages/producer/scripts/check-golden-font-licences.mjs`: family names must match exactly (trailing style words aside), not by prefix. Data URIs are found in any case or spacing, percent-encoded or not. Bare base64, raw font files and TTC/OTC collections are read face by face. Unsupported formats are errors. Every Reserved Font Name in a licence text is read, quoted or not, as well as those a face declares in its own name table. Paths are matched by segment on every platform, and finding no goldens is an error. The bundled font data (the generator's Fontsource sources and `fontData.generated.ts`) is checked too. `packages/producer/package.json`: `test:font-licences` runs the tests and the check, `test` runs `test:font-licences` first, and `build` runs the check with `--bundled-only` after `build:fonts`, which reuses an existing generated file. `skills/embedded-captions/modes/standard/fonts/build-fonts-css.cjs`: any font file in `files/` that it doesn't embed and check is an error, detected by content as well as extension. A subset's name-table family, OS/2 weight and italic flag must match its file name; `fonts.css` is unchanged. `packages/producer/tests/README.md` and `tests/FONT-LICENSES/README.md`. The entry dated 2026-10-08 above ("embedded fixture fonts…") now says that the 50 removed commercial faces were Google Fonts licensed kits, not system-font captures. |
| **Reason**       | No modified font may be shipped or bundled under a Reserved Font Name (lab-0062 legal ruling), and the checks that enforce this must not be bypassable (review of Mira #2, round 4).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
