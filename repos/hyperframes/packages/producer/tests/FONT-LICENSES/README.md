# Licences for fonts embedded in the producer test fixtures

Modified by Coco, 2026-10-08 (lab-0062 legal review). See `repos/hyperframes/MODIFICATIONS.md`.

Many fixtures' expected output (`<fixture>/output/compiled.html`) embeds web-font subsets as base64 `data:` URIs in `@font-face` rules. The compiler wrote them when the baselines were generated: it fetched the Fontsource package for each family, or captured a system font from the generating machine. Every font still embedded in these files is under the SIL Open Font License 1.1, and none of them has a Reserved Font Name. Its licence text is in this folder, copied byte for byte from google/fonts at commit `2eb0b48d5f760f62e286216f0859a8c540dbc1bd`.

Commercial system fonts that had been captured into eight baselines were removed in the same review: Helvetica, Helvetica Neue, Impact and Monotype Garamond (50 faces). They were in `style-3-prod`, `style-7-prod`, `style-8-prod`, `style-15-prod`, `style-16-prod`, `style-18-prod`, `sub-comp-id-selector` and `sub-comp-t0`.

IBM Plex Mono (Regular and Bold, 2 faces) was removed from `style-11-prod`. Its OFL text reserves the font name "Plex", and legal ruled that the trimmed web subset is a Modified Version, which may not keep that name. The fixture's CSS still asks for "IBM Plex Mono" by name (from Google Fonts at render time, or the host); no Plex font data is stored here. No IBM Plex file ships anywhere in Mira, so no upstream checksum applies.

`packages/producer/scripts/check-golden-font-licences.mjs` (run by `bun run test`, after `bun run test:update`, or alone with `bun run test:font-licences`) fails if a golden embeds a font whose family isn't in the table below, or whose names use a Reserved Font Name declared in this folder. Add the licence text and a row here before committing a golden with a new family.
